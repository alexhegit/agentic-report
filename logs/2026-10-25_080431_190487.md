## 本周重点

### 1. Cosmos Lab｜Interactive World Simulation with Cosmos for Physical AI

- **发布日期：** 2026-10-20
- **事实：** Cosmos Lab 发布统一的实时、流式交互世界模拟方案，并开放三类 Cosmos3-Nano 16B 后训练检查点：面向双臂机器人动作/相机轨迹的 Sim-Bimanual、将深度/分割/边缘等模拟控制转为写实视频的 Sim-Transfer，以及联合生成多视角 RGB 与 LiDAR 的 Sim-Auto。[4]
- **性能与部署：** 官方项目页报告 Sim-Bimanual 在单张 GB300 上达到 48.1 FPS、166 ms 延迟（480p）；Sim-Transfer 在单张 GB200 上为 15.85 FPS、240 ms；Sim-Auto 在 16 张 GB200 上生成 7 路 RGB 与 LiDAR，达到 16.7 FPS。三者工作负载与硬件不同，不能据裸延迟直接排名。[4]
- **为何重要（分析）：** 这把 Cosmos 从离线视频生成推进到可由机器人或车辆控制信号持续驱动的闭环环境，直接面向策略评估、强化学习和合成示范生成。公开模型卡、训练/推理配方和代码降低了复现实验的门槛，但官方性能目前集中在 Blackwell 数据中心 GPU，并不等同于边缘端可实时部署。[5][6][7]
- **开源状态：** 代码 + 模型；三个模型均为 V1.0，模型卡标注 OpenMDW 1.1，可商用或非商用。[5][6][7]
- **置信度：高。**

### 2. GEAR｜Agentic World Action Models（AW-0）

- **发布日期：** 2026-10-21（arXiv v1）
- **事实：** AW-0 在统一 Mixture-of-Transformers 中联合生成程序代码、未来视频和机器人动作，并通过自动标注流程把机器人与人类示范整理成可复用技能库；论文在 RoboTwin 2.0 和真实双臂操作上报告了相对 VLA/WAM 基线的任务表现、语言遵循、语义推理与鲁棒性提升。[1]
- **实验室归属：** 论文含 NVIDIA 作者，Yuke Zhu 与 Linxi “Jim” Fan 为共同指导作者；二人也是 GEAR 官网列出的负责人，因此本报告将其归入 GEAR。该归属是基于团队负责人交叉核验，而非论文显式写出“GEAR”。[1][3]
- **为何重要（分析）：** 工作把可复用程序化技能作为世界模型、规划和连续控制之间的中间接口，方向上超越仅预测动作或视频的单一 WAM/VLA。它还公开了完整训练、RoboTwin 与真实机器人后训练代码及预训练检查点，便于验证“代码规划是否真正改善动作预测”。[2][10]
- **开源状态：** 论文 + BSD-2-Clause 代码 + 预训练模型；未见 GitHub Release/tag，仓库初始代码提交早于本统计期，故本期新增事件按“论文正式公开并配套开源资产”计一次，不把 10 月 22 日 README 格式修复另算更新。[1][2][10]
- **置信度：中高。**

## 趋势判断

1. **分析：世界模型正在从“生成视频”转向“闭环可控环境”。** Cosmos 的动作、空间控制与多传感器流式生成，以及 AW-0 的代码—视频—动作联合建模，都把预测结果放回控制回路。[1][4]
2. **分析：程序化技能正成为长时程机器人策略的结构层。** AW-0 用短程序组织可复用技能，并允许程序执行与动作头之间的混合决策，显示“代码即规划接口”开始与 WAM 融合。[1][2]
3. **分析：开放资产增多，但复现算力仍偏数据中心级。** Cosmos 三个检查点和配方已开放，而官方实时指标主要基于 GB200/GB300；跨硬件复现前需重新测量吞吐、延迟和内存边界。[4]
