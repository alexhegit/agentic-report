# Physical AI Daily Scout｜2026-11-25

## Papers
- **ACAP：异步编码 Agent 机器人控制** — 将机器人按手臂、夹爪、躯干和底盘拆成可并发推理、执行的持久 Agent，并用 hyper-agent 动态协调耦合动作；72 次真机 rollout 中，相比单 Agent Direct Policy 将任务平衡耗时降低 28.2%。[来源](https://arxiv.org/abs/2611.31205)[1]
- **Knowing What You Carry：液体载荷世界模型** — 用 GPU 并行液体—多体仿真生成高保真参考，再以“物理先验＋隐状态估计＋学习残差”在单次 20 Hz 控制周期内批量评估数千条候选轨迹，面向近侧翻极限的安全规划。[来源](https://arxiv.org/abs/2611.28387)[2]

## Projects
- **Skeptic 首次公开** — 新仓库给 LLM 机器人 Agent 增加基于本体、深度观测的失败时间线，以及“成功尝试＋验证器判定＋哈希、版本和语法检查”后才写入技能库的准入门；已提供 LIBERO-Pro 80 任务配置、隔离沙箱和完整 campaign 启动脚本，但完整复现实验要求 4×H100。[来源](https://github.com/lmsdss/Skeptic/commit/ed5645f6e5b05a838189354898072b9f75cb04e7)[3]

## Industry
- **XPENG 发布 WorldGPT** — 官方称该云端 teacher model 统一学习汽车、船、无人机、单/双臂机器人和人形机器人六类载体，并向端侧专用模型蒸馏；其公开结果包括50个单臂任务平均95.2%成功率。[来源](https://www.xpeng.com/news/01a20bcf44b3a1e838d68a02a2110153)[4]
- **ATOM 获三家日本大行45亿日元融资额度** — 融资额度将用于自建 GPU 集群和启动双足人形机器人量产体系；其中瑞穗的15亿日元是对8月协议的换约，额度并非已提款资金。[来源](https://prtimes.jp/main/html/rd/p/000000008.000172692.html)[5]

## Signal
研究与工程两端都在拆解“单体智能”瓶颈：控制侧用多 Agent 并发和物理锚定预测提高闭环效率，开发侧则用可验证技能准入控制自我改进风险。[1][2][3]

产业侧同步把跨载体模型、训练算力和量产准备打包建设，竞争对象正从单一机器人模型扩展为完整的数据—计算—硬件闭环。[4][5]
