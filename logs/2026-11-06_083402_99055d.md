# GitHub 周度工作总结（2026-10-30 08:31—2026-11-06 08:31，CST）

## 本周概览

本周工作集中在 AMD/ROCm 推理落地、机器人闭环验证和部署准备。vla-hip 连续发布三个版本，新增 VLA-JEPA、GEAR-SONIC/Unitree G1 路径及 Isaac-GR00T 协议，并用 LIBERO 与重建闭环给出准确率和延迟证据。机器人侧，Microduck 冲刺策略推进到 ONNX 与板载运行时，SO-101 抽屉任务完成锁定测试和 RGB/RGB-D 对照。个人仓库还发布了 h3-hip 的 Pika H3 Flex 支持，并推动多项上游 ROCm 修复闭环。

## alexhegit

### 1. h3-hip 发布 Pika H3 Flex，并更新 MI210 性能基线

- 发布 **h3-hip v0.17.0**，增加可选 Pika H3 Flex 6-step LoRA、首尾帧适配、下载工具及 MI300X 示例；该路径默认关闭，不改变既有生成流程。
- 在当前主干重新测量 MI210：864×480、15 秒视频的 dense / token reduction 分别为 **698 / 476 秒**，短视频 `fox-s2` 为 **10.76 秒**，形成完整 gfx90a 运行账本。
- 依据：[v0.17.0 Release](https://github.com/alexhegit/h3-hip.c/releases/tag/v0.17.0) · [PR #13](https://github.com/alexhegit/h3-hip.c/pull/13) · [MI210 retake](https://github.com/alexhegit/h3-hip.c/commit/9c558414bacc73cee4828d9fd0518768e4f09fc5)

### 2. 上游 ROCm 与训练健壮性问题取得闭环

- Uni-SuperMimic 将此前 R9700 PR 中的平台无关修复和 ROCm 条件化规避整理为上游 [PR #31](https://github.com/Motphys/Uni-SuperMimic/pull/31) 并合并；原 [PR #11](https://github.com/Motphys/Uni-SuperMimic/pull/11) 因被替代而关闭。进入主干的内容包括原生 MuJoCo 状态同步、近垂直 heading、非有限值保护和 ROCm 数值路径。
- semantic-router 的 GPU 权重加载已改为分片暂存；gfx1151 复测确认 d3 不再因完整 host 副本而 OOM，因此 [Issue #5168](https://github.com/vllm-project/semantic-router/issues/5168) 正式关闭。
- 进一步定位 ROCm 7.2.x `AsyncEventsLoop` 的 event-age busy-spin，提交了可复现程序、补丁和量化结果：回移两个上游提交后，GR00T 阻塞等待路径由约 **1.04 个 CPU 核降至 0.09 个**。
- 依据：[ROCm Issue #15004](https://github.com/ROCm/rocm-systems/issues/15004)

## rocPAI-Forge

### 1. vla-hip 从三模型原型推进到 v0.2.0 发布

- 连续发布 [v0.1.0](https://github.com/rocPAI-Forge/vla-hip.c/releases/tag/v0.1.0)、[v0.1.1](https://github.com/rocPAI-Forge/vla-hip.c/releases/tag/v0.1.1) 和 [v0.2.0](https://github.com/rocPAI-Forge/vla-hip.c/releases/tag/v0.2.0)，形成可复现的 gfx1151 VLA 推理版本线。
- 新增 **VLA-JEPA**：双视角 BF16 / INT8 为 **52.9 / 51.7 ms**，四个 LIBERO suite 平均成功率约 **98.1% / 98.4%**，同一 harness 的 vla.cpp CPU 为 97.5%。
- 接入 GR00T N1.7 的 **GEAR-SONIC / Unitree G1** checkpoint及 Isaac-GR00T policy-server 协议。BF16 4-step 为 **61.4 ms**，INT8 FFN 2-step 为 **38.0 ms**；重建闭环下连续运行 30 分钟、9,000 次调用，BF16 p50/p99 为 **64.7/66.0 ms**。
- 同期将 LIBERO GR00T N1.7 从 72.6 降至 **71.3 ms**，并统一四模型的 CPU、BF16、INT8 和闭环报告格式。v0.2.0 发布说明记录 clean build、`make test`、36/36 跨版本 bitwise 检查及服务器测试均通过。
- 依据：[v0.2.0 Release](https://github.com/rocPAI-Forge/vla-hip.c/releases/tag/v0.2.0) · [GEAR-SONIC 实现](https://github.com/rocPAI-Forge/vla-hip.c/commit/3731a3ed1a) · [Isaac-GR00T Server](https://github.com/rocPAI-Forge/vla-hip.c/commit/4c7c31e6bc)
