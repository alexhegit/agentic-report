# GitHub 周度工作总结（2026-11-20 08:31—2026-11-27 08:31，CST）

本周主要推进三条主线：H3 验证 NVMe→VRAM 直读以降低大模型权重加载成本；LeRobot 在 MI300X 上完成大规模 ROCm/FSDP 覆盖并向上游提交修复；rocPAI-Forge 则发布 SO-101 Agent Harness 首个仿真预览，并将 MicroDuck 扩展为包含训练、展示、策略切换和跨模拟器验证的完整运动栈。MicroDuck 连续发布 v0.4.0、v0.5.0、v0.5.1，AMD 官方 MicroDuck playbook 也已合并。

## alexhegit

### 1. H3 打通 hipFile NVMe→VRAM P2P 权重加载

- 新增可选 hipFile 与 O_DIRECT 加载器；hipFile 将对齐后的权重块直接读入 VRAM scratch slot，再经 SDMA 写入 tensor，避免主机页缓存挤压及相关 KFD queue eviction。
- R9700 冷启动 fox-fast 从 **42.40 秒降至27.77秒（-34.5%）**，FastH3 冷启动缩短15.1%，Ref2VA缩短22.8%，`--serve` 重载缩短19.9%；读取约6 GiB/s，并以 DRAM 流量证明实际走P2P路径。所有已测模式保持MD5一致，`hip-test`、`serve-regression`和六项`hip-functional`通过。
- 当前实现还增加多slot并发、低内存自动启用规则、pageable readback pinned staging，以及P2P、A/B和KFD eviction诊断工具。
- 依据：[H3 PR #22](https://github.com/alexhegit/h3-hip.c/pull/22) · [跨设备验证 Issue #23](https://github.com/alexhegit/h3-hip.c/issues/23)

### 2. 完成 LeRobot MI300X/ROCm 训练实践并向上游反馈

- 系统验证LeRobot 0.7的27种策略：单卡和2卡DDP全部通过；24种策略通过FSDP2，ACT、π0、FastWAM、WALL-OSS 0.5、Cosmos3 Edge扩展至8卡，并覆盖HSDP、混合精度、梯度累积、断点续训和换分片数恢复。
- 定位HIP初始化收窄CPU affinity导致的多卡瓶颈：设置`AMD_CPU_AFFINITY=0`后，ACT 8卡由 **706提升至4,122 samples/s**，达到单卡7.1倍；对应Docker修复及ROCm已知问题文档已提交LeRobot。
- 同期提交TOPReward短视频padding、sample-weighting提前校验等修复，并记录FSDP resume、size-based wrapping、Praxis数据重命名及NATTEN ROCm路径问题。
- 依据：[实践报告](https://github.com/alexhegit/lerobot-rocm/blob/main/reports/practice-report.md) · [LeRobot PR #5472](https://github.com/huggingface/lerobot/pull/5472) · [PR #5473](https://github.com/huggingface/lerobot/pull/5473) · [NATTEN Issue #354](https://github.com/SHI-Labs/NATTEN/issues/354)
