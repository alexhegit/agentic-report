# GitHub 周度工作总结（2026-10-16 08:31—2026-10-23 08:31，CST）

## 本周概览

本周工作集中在 **AMD/ROCm 上的 VLA 推理落地与性能优化**、机器人策略闭环验证，以及强化学习训练资产的可复现化。个人侧完成了 FlashRT 的 R9700 Pi0.5、gfx1151 XR-1 适配，并向 semantic-router 合入 gfx1151 镜像修复。rocPAI-Forge 新建原生 HIP VLA 引擎，将 Pi0.5 在 gfx1151 上从初始约 1 秒级优化到 130–150 ms 区间，同时推进 LingBot-VLA 2.0 至 Home20 25/60。

## alexhegit

### 1. 扩展 FlashRT 的 AMD VLA 支持

- 为 **Radeon AI PRO R9700 / gfx1201** 增加 Pi0.5 BF16 正式路径，并完成 gfx12 WMMA fragment layout、small-M GEMM 和 encoder attention 适配。实测 Pi0.5 单帧延迟由 hipBLASLt 路径约 60.0 ms 降至 **54.8 ms**；启用两帧缓存时约 **38.3 ms**。
- 为 **gfx1151** 增加 XR-1 5B 与 RoboCasa 推理、可选原生 HIP DiT 和全模型 HIP Graph；真实观测下 Graph 路径保持动作一致，并取得约 2.7%–6.7% 的 P50 降幅。
- 依据：[R9700 Pi0.5 PR #237](https://github.com/flashrt-project/FlashRT/pull/237) · [XR-1 PR #233](https://github.com/flashrt-project/FlashRT/pull/233)

### 2. 修复 semantic-router 的 gfx1151 ROCm 部署链路

- 定位并验证大模型 GPU 加载已不再生成完整主机副本：48.6 GiB d3 权重在 gfx1151 上的主机匿名内存峰值降至约 **5.5 GiB**，原始 OOM 问题已解除。
- 随后修复 ROCm 镜像裁剪掉 gfx1151 rocBLAS/hipBLASLt 库的问题。修复已合并，gfx1151 上 d3 成功启动，并完成 JevBench **231/231、0 失败**。
- 依据：[镜像修复 PR #5308](https://github.com/vllm-project/semantic-router/pull/5308) · [主机副本 Issue #5168](https://github.com/vllm-project/semantic-router/issues/5168)

### 3. 建立跨平台 Pi0.5 性能对照与证据链

- 在私有知识库中整理 vla-hip.c、FlashRT gfx1151、R9700 与 NVIDIA Thor 的同形状对比，纠正此前 13-token 与 144-token prompt 混比的问题。
- 补充 roofline、阶段拆分、原始输出和校验信息；当前同为 13-token 形状时，vla-hip.c 记录约 **131.32 ms BF16 / 125.29 ms INT8 expert**。
- 依据：[alexhegit/llm-wiki](https://github.com/alexhegit/llm-wiki)

## rocPAI-Forge

### 1. 新建 AMD 原生 VLA HIP 推理引擎

- 新建 [vla-hip.c](https://github.com/rocPAI-Forge/vla-hip.c)，实现面向 AMD GPU 的 SmolVLA 与 Pi0.5 推理，包括 WMMA GEMM、Flash Attention、HIP Graph、数值门禁和 Python 接口。
- SmolVLA 在 gfx1151 上达到约 **46 ms（单视角）/62–70 ms（双视角）**；Pi0.5 从初始约 1037 ms 逐步优化至约 **145 ms BF16 / 133 ms INT8 expert**，后续同形状测量进一步达到约 131/125 ms。
- 新增 prefix frame cache 与 FlashRT 异步 action-chunk runner：缓存场景平均调用约 **94 ms**，并用实测时间线澄清不同控制频率下的 deadline miss 和 held-action 比例。

### 2. 推进 Lab 01 模型接入与 LingBot-VLA 2.0 闭环效果

- 完成外部 VLA policy 边界、xVLA 10K Home20 **47/60** 结果归档、checkpoint 发布和验证模型索引。
- LingBot-VLA 2.0 经 inverse-slot gripper read-back 修复后，从此前公平适配下的 **0/60** 提升至默认采样器 **25/60**；已发布 20K checkpoint、正式 setup/eval/push 入口和复现文档，并移除失效的 LingBot-VA EEF 与 DAgger 路径。
- 依据：[LingBot-VLA 2.0 PR #20](https://github.com/rocPAI-Forge/so101-simstudio/pull/20) · [外部 VLA 接入 PR #18](https://github.com/rocPAI-Forge/so101-simstudio/pull/18) · [xVLA checkpoint PR #16](https://github.com/rocPAI-Forge/so101-simstudio/pull/16)

### 3. 强化 MicroDuck RL 的可复现训练资产

- 发布经检查的 velocity、standup、velstand checkpoint 与回放素材，其中 velstand 策略可从俯卧和仰卧恢复站立。
- 新增纯 SAC 速度训练器，引入镜像损失、步态相位观测和跌倒代价，并补充奖励、对称性和训练器测试；教程同步收敛到已验证的单 GPU 配置，去除缺乏稳定依据的 wall-clock 描述。
