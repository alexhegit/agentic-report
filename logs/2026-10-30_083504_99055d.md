# GitHub 周度工作总结（2026-10-23 08:31—2026-10-30 08:31，CST）

## 本周概览

本周重点是完善 AMD/ROCm 原生推理与训练链路：Flint gfx1151 引擎从底层模型执行推进到可部署服务，vla-hip 新增 GR00T N1.7 并继续压缩 SmolVLA、Pi0.5 延迟。上游贡献方面，FlashRT 的 R9700 Pi0.5 支持已合并，Mobile-4DGS 和 Uni-SuperMimic 的 ROCm 适配进入评审。机器人侧清理了 LingBot 历史事项，并开始验证不泄漏目标位姿的抽屉开合任务。

## alexhegit

### 1. 建成 Flint gfx1151 原生推理与服务链路

- 新建并完成 [flint-hip.c](https://github.com/alexhegit/flint-hip.c) 的主干实现：覆盖 INT4 checkpoint 校验与受限加载、49 层 resident HIP 推理、tokenizer/采样、OpenAI 与 Anthropic API、工具调用、前缀缓存和双会话连续批处理。
- 真实加载 **22.57 GB** Flint checkpoint，完成 CLI、OpenAI/Anthropic 流式请求、并发工具调用、断连隔离及恢复验证；随后将 REC 集成提交为上游 PR。
- 主干进一步将 LM head 从逐 token prefill 推迟到已提交 chunk，并修正取消边界，避免无效 logits 计算。
- 依据：[flint-hip.c](https://github.com/alexhegit/flint-hip.c) · [REC PR #43](https://github.com/recursive-oss/rec/pull/43) · [主干最终修复](https://github.com/alexhegit/flint-hip.c/commit/be641d02ea905b8c1e96d398e4a7e725bd04da96)

### 2. 扩大 AMD 图形与机器人训练支持

- 为 Mobile-4DGS 增加可选 gsplat ROCm 后端，在 **MI300X** 上验证静态 3DGS 的 forward/backward、densification、保存及约 100 it/s 训练循环，同时保持原 CUDA 扩展优先且行为不变。当前边界是 neural-attribute/SH 压缩和动态 4D 路径仍依赖 CUDA。
- 修复 Uni-SuperMimic 在 **Radeon AI PRO R9700** 原生 MuJoCo 路径中的状态同步、数值稳定性和近垂直 heading 问题。最终代码上的新训练在 12,000 updates 达到 **40/40 无失败、归一化回报 0.8330**，训练耗时约 3.23 小时；测试为 92 passed、2 skipped。
- FlashRT 的 R9700 Pi0.5 BF16 支持已于本周合并，结束上周的待合并状态。
- 依据：[Mobile-4DGS PR #2](https://github.com/xiaobiaodu/Mobile-4DGS/pull/2) · [Uni-SuperMimic PR #11](https://github.com/Motphys/Uni-SuperMimic/pull/11) · [FlashRT PR #237](https://github.com/flashrt-project/FlashRT/pull/237)

### 3. 建立可迁移的自动情报知识库

- 新建 [agentic-report](https://github.com/alexhegit/agentic-report)，将物理 AI 与 AMD 市场定时报告自动归档为静态站点、全文检索和知识图谱，并支持飞书深链。
- 仓库内置任务定义、skill、幂等安装器和入库脚本，可由其他 Hermes 主机直接接管；同时补充日历导航、按月选择、最新日期默认页及无界搜索。
- 依据：[agentic-report](https://github.com/alexhegit/agentic-report) · [在线站点](https://alexhegit.github.io/agentic-report/)

## rocPAI-Forge

### 1. vla-hip 新增 GR00T N1.7 并继续优化三类 VLA

- 在 [vla-hip.c](https://github.com/rocPAI-Forge/vla-hip.c) 完成 GR00T N1.7 的 gfx1151 HIP 移植，包含 CPU 八组输入数值门禁、packed GEMM、短序列 FP32 attention、HIP Graph 和可选 INT8 DiT。
- 通过 mid-T GEMM、vision tile 和 K 起点轮换，将双视角、148-token、40-action 的 GR00T N1.7 延迟从 **92.6 ms 降至 80.2 ms BF16 / 69.0 ms INT8 DiT**，相对 CPU 分别约 6.6×/7.7×。
- 同期将三相机 SmolVLA 压至 **60.8 ms BF16 / 58.6 ms INT8 expert**，并继续优化 Pi0.5 prefix GEMM 与 attention；补充了与 VLA-HWBench、FlashRT 和 Jetson Thor 的同形状对照。
- 依据：[GR00T 初始移植](https://github.com/rocPAI-Forge/vla-hip.c/commit/db17d7497bae573d50645d4f28064a918ba80df6) · [GR00T 最新结果](https://github.com/rocPAI-Forge/vla-hip.c/commit/de4afc1fe3b843163be93b9bb4d14350b83e7f36) · [SmolVLA 优化](https://github.com/rocPAI-Forge/vla-hip.c/commit/6228fcb5ecda440763d05f2363771bf878a6e9cc)
